# Breaks inside a plate, in angstrom.
#
# coverage_gaps.txt cuts the spectrum where no line of any species was
# recorded: those are the joins between one exposure and the next, and they
# are measured.  This file carries the other kind of break, the one that
# happens inside a single plate and leaves no gap in the line list.
#
# The plates are rigid flat glass covered by emulsion, and the spectrograph
# bends them onto the Rowland circle with two to four mechanical holders.
# The plate is pinched at each holder, so the dispersion curve - smooth
# everywhere else - is deformed there, and the calibration on one side of a
# holder does not carry to the other.  A break of this kind is found by eye,
# from a trend in d_lambda_A that stops and restarts, and so each one is
# entered here by hand with the evidence for it.
#
# One wavelength per line, optionally followed by a comment.  A break inside
# a block splits it; a break that falls in a blind stretch does nothing.
#
